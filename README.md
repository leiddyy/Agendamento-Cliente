# 📅 Agendamento Cliente — Sistema de Agendamento Online

Sistema web de auto-agendamento para salões e clínicas de estética, com fluxo completo para o cliente e integração com WhatsApp.

## 📋 Sobre o projeto

O sistema permite que o cliente agende seu próprio horário em 3 passos simples:

1. **Serviço** — escolha do procedimento desejado
2. **Data & Hora** — seleção de data e horário disponível
3. **Confirmação** — dados do cliente e confirmação do agendamento, com envio de comprovante via WhatsApp

Os agendamentos são armazenados em banco de dados, garantindo consulta e controle real dos horários.

🔗 **Demo ao vivo:** [agendamento-cliente-production.up.railway.app](https://agendamento-cliente-production.up.railway.app/?salon=eduarda-souza)

## 🛠️ Tecnologias utilizadas

- Node.js
- JavaScript
- Banco de dados

## 🚀 Funcionalidades

- [x] Seleção de procedimento por categoria
- [x] Consulta de horários disponíveis por data
- [x] Cadastro dos dados do cliente no agendamento
- [x] Confirmação e envio de comprovante via WhatsApp
- [x] Armazenamento dos agendamentos em banco de dados

## 💻 Como executar o projeto

```bash
# Clone este repositório
git clone https://github.com/leiddyy/Agendamento-Cliente.git

# Acesse a pasta do projeto
cd Agendamento-Cliente

# Instale as dependências
npm install

# Execute o projeto
npm start
```
